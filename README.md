Pertempuran 5 lawan 5 — **Tim Biru** melawan **Tim Merah**. Menang 5 ronde dulu (maksimal 9 ronde). Setiap kill +$300, menang ronde +$1.000. Belanjakan uangmu di fase beli: MP5, SPAS, AWP, Armor, dan Smoke Grenade.

## Cara main

- **WASD** gerak · **Mouse** bidik · **Klik** tembak · **R** isi ulang
- **Shift** jalan pelan · **C** jongkok · **Spasi** lompat · **G** lempar smoke · **1–4** ganti senjata · **P / Esc** jeda
- Dua peta: **Puncak Salju** (salju putih, pohon pinus) dan **Gurun Pasir** (pasir panas, kaktus).
- Menara di tengah peta bisa dinaiki lewat ramp selatan — tapi posisi spawn musuh terlihat dari atas, jadi hati-hati.
- **Latihan Tembak**: 5 target (3 diam di 6/10/14 meter, 2 bergerak), 60 detik. Rekor tersimpan di perangkatmu.
